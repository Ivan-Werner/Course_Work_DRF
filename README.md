# Course_Work_DRF
### В рамках проекта реализована бэкенд-часть SPA веб-приложения "Трекер привычек"

## Описание задач:
* Добавлены необходимые модели 
* Реализованы эндпойнты для работы с фронтендом
* Создано приложение для работы с Telegram и рассылками напоминаний

## Реализованы валидаторы:
* Исключен одновременный выбор связанной привычки и указания вознаграждения.
* Время выполнения должно быть не больше 120 секунд.
* В связанные привычки могут попадать только привычки с признаком приятной привычки.
* У приятной привычки не может быть вознаграждения или связанной привычки.
* Нельзя выполнять привычку реже, чем 1 раз в 7 дней.

### Реализована пагинация с выводом по 5 привычек на страницу

### Настроены права доступа

### В проекте присутствуют эндпойнты:
* Регистрация.
* Авторизация.
* Список привычек текущего пользователя с пагинацией.
* Список публичных привычек.
* Создание привычки.
* Редактирование привычки.
* Удаление привычки.

Реализована работа с отложенными задачами и интеграция с
Telegram
